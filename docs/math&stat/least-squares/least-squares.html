Introduction

The least squares method remains one of the most widely used optimization tools in machine learning. Despite its simplicity, it underpins many of the models organizations rely on for forecasting, risk scoring, and operational decision‑making.

At its core, least squares identifies the model parameters that minimize the squared gap between predictions and reality. This foundational idea extends naturally to more advanced methods such as regularized regression, generalized linear models, and even the complex loss surfaces optimized in deep learning.

A simple way to visualize this is through a DIY analogy. Imagine an enthusiastic home improver who starts drilling holes for a shelf before taking proper measurements. The holes end up scattered—some close to where they should be, others noticeably off. When it’s finally time to mount the shelf, the only practical strategy is to position it so that it covers as many holes as possible while keeping the overall alignment reasonable. In effect, the installer chooses the placement that minimizes the “total error” across all the misplaced holes.

Least squares works the same way: it finds the position or set of parameters that best reconciles imperfect data, reducing the overall discrepancy in the most balanced way possible.

Fit a least squares model

Imagine the wall with holes and now you are holding the shelf to fit it through maximum holes. If you wish to go into details the output of OLS regression results can be looked up with the help of copilot for detailed explanation.

import statsmodels.api as sm

X = data[["x1", "x2"]]
X = sm.add_constant(X)
y = data["y"]

model = sm.OLS(y, X).fit()
model.summary()

And few graphs

Visuals help our understanding better than tables

Predicted vs. Actual Values

A quick way to assess model performance

import matplotlib.pyplot as plt

pred = model.predict(X)

plt.figure(figsize=(7,5))
plt.scatter(y, pred, color="navy")
plt.plot([y.min(), y.max()], [y.min(), y.max()], 'r--')
plt.xlabel("Actual")
plt.ylabel("Predicted")
plt.title("Predicted vs Actual Values")
plt.tight_layout()
plt.show()

Residual Plot

A clean residual plot signals stability and reliability.

residuals = y - pred

plt.figure(figsize=(7,5))
plt.scatter(pred, residuals, color="darkgreen")
plt.axhline(0, color='red', linestyle='--')
plt.xlabel("Predicted")
plt.ylabel("Residual")
plt.title("Residual Plot")
plt.tight_layout()
plt.show()

Coefficient Bar Chart

A simple way to communicate variable importance.

coef = model.params

plt.figure(figsize=(7,5))
coef.drop("const").plot(kind="bar", color=["#1f77b4", "#ff7f0e"])
plt.title("Model Coefficients")
plt.ylabel("Coefficient Value")
plt.tight_layout()
plt.show()

Observations

  • Both predictors meaningfully influence the outcome, with x1 showing a slightly stronger effect.
  • The model demonstrates stable residuals, indicating a reliable linear relationship.
  • The predicted vs. actual plot shows tight alignment, reinforcing that least squares provides a strong baseline model.
  • This type of model is often used as a benchmark before deploying more complex ML architectures.

Real‑World Applications

  1. Forecasting & Planning - Revenue forecasting, Workforce planning, Inventory optimization
  2. Risk & Compliance - Credit scoring, Fraud detection baselines, Early‑warning indicators
  3. Healthcare & Life Sciences - Outcome prediction, Dose–response modeling, Clinical signal detection
  4. Operations & Engineering - Sensor calibration, Predictive maintenance, Quality control analytics
  5. Machine Learning Infrastructure - Loss minimization, Embedding alignment, Regression layers inside deep models

Least squares is not just a statistical technique — it’s a strategic tool that helps organizations make decisions grounded in data rather than intuition.
